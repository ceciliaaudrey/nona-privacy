# Data Retention Policy

## Retention Periods

### User Account Data
- Active accounts: Retained indefinitely
- Inactive accounts (2+ years): Deleted after 90 days notice

### Transaction Data
- Retained for 7 years for compliance

### Log Files
- Server logs: 30 days
- Error logs: 90 days

## Deletion Procedures

Data is securely deleted using industry-standard methods to prevent recovery.

## Legal Holds

Data may be retained longer if required by law or litigation.
